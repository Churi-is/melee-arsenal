# Asset Provenance

## Generated assets

InkBlade meshes and textures are generated by the pure-Python pipeline in `tools/inkblade_gen/` using Pillow. The kit contains 22 modular parts: five blades, five grips, seven accessories, and five elemental emitters. Texture atlases contain the manufacturer palettes, surface treatments, markings, and ink linework.

`tools/inkblade_upk/` compiles the generated GLB meshes and PNG textures into the UE3 packages `MeleeArsenalMeshes.upk` and `MeleeArsenalTextures.upk`. `tools/compile_inkblade_upk.py --fingerprint-only` reports the content fingerprint used by the install command to detect stale packages. Build dependencies are pinned in `requirements.txt` and `pyproject.toml`.

## Donor asset

`tools/inkblade_upk/donors/weap_pistol_donor.upk` is a stripped, header-only extract of the stock `Weap_Pistol` package used as the UE3 package template. It contains the package summary and skeletal-mesh header skeleton; no pistol geometry, textures, or sounds are included.

## Runtime audio and effects

No custom sound files are bundled. Combat audio and visual effects use Borderlands 2 `AkEvent`, `CameraAnim`, and `ParticleSystem` assets resolved through `unrealsdk`.

- Willow2 Mod Manager (GPLv3) hosts the in-game mod.
- Python (PSF License) runs the offline tools.
